안녕하세요. 이 블로그는 **마크다운 파일**을 읽어서 정적인 블로그 페이지로 보여주는 아주 작은 프로젝트입니다.

## 왜 이렇게 만들었나

- 프레임워크 없이 순수 HTML/CSS/JS로만 동작합니다.
- `posts/` 폴더에 `.md` 파일을 추가하고 `manifest.json`에 한 줄만 등록하면 새 글이 생깁니다.
- 다크 모드와 모바일 화면을 모두 지원합니다.

## 코드 블록 예시

```js
function greet(name) {
  return `안녕하세요, ${name}님!`;
}

console.log(greet("세계"));
```

## 인용문 예시

> 읽기 좋은 글이 가장 좋은 글이다.

| --- | --- |
| 다크 모드 | 시스템 설정 감지 + 토글 버튼 |
| 반응형 | 모바일에서도 레이아웃 유지 |

읽어주셔서 감사합니다!
